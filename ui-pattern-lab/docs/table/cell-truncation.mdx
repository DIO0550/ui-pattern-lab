一般化した表示制限の比較は [表示制限](/ellipsis-display) を参照してください。このページでは、テーブルの行高と列密度を崩さない `cell-truncation` の具体例に絞って扱います。

table では「列を比較しやすい行高を維持すること」が主目的です。list / card / summary / disclosure を横断する generic な表示制限の判断は [表示制限パターン](/patterns/ellipsis-display-designs) に切り分けています。
