# Tabs Inline Panel Switcher

## Summary

同一ページ内で panel や section を切り替える controller。

## Scope

- settings panel
- dashboard section
- docs detail switch

## Notes

- page navigation ではなく、同一 view 内の切り替えとして扱う
- `tablist` / `tabpanel` の基本 semantics を崩さない
