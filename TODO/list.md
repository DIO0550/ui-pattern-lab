# List

## Summary

同種の項目を縦方向に並べ、情報スキャンや項目操作を支える data display。

## Scope

- message list
- settings list
- notification list

## Notes

- table は列構造、list は項目単位の読み取りとして責務を分ける
- clickable / selectable / draggable は別の behavior として扱う
- trailing action と trailing meta を混同しない
